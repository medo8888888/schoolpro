Manager Workflow Guide

Use this page to manage scheduling and project status updates without relying on stored records.
  1. Step 1: Create or update a project target with client, project, engineers, date/time, visits, and price.
  2. Step 2: Assign visitation from that project only after visits/date are set.
  3. Step 3: Use lifecycle actions carefully: Reassign, Remove Engineer, Terminate, Remove Project.
  4. Step 4: Export by week from Export Excel after selecting the week filter.
Reassign = change project engineer list Remove Engineer = remove one engineer Terminate = stop new scheduling Remove Project = delete target record
