1. Map and Morning Overview

Open the Manager page and review the live map plus the morning overview first.

  1. Check the mapto see which staff are active and where they are.
  2. Review the morning overviewfor attendance, late arrivals, and pending items.
  3. Use those signalsbefore you create or change project work.

2. Add a Project

Use the Project Visit Targets section to add a new project target.

  1. Fill in client name and project name.
  2. Enter engineer usernamesand the visit date/time.
  3. Set the required visits and pricethen save the project target.

3. Remove or Manage a Project

Projects can be maintained from the same target list.

  1. Use the target card actionsto terminate, soft delete, or recover a project.
  2. Reassign engineersif the visit owner changes.
  3. Remove an engineerfrom the project if they are no longer assigned.

4. Assign Visitation

After the project exists, assign the visit to the employee.

  1. Select the projectfrom the Add Visitation section.
  2. Choose the employee(s)who should receive it.
  3. Save the visitand it will appear in the scheduled visits list.

Detailed Daily Flow

Use this order every day to keep the office and field team aligned.

  1. Start with the overview. Review who is active, who is late, and which visits are still pending.
  2. Create or update project targets. Add new work, change visit details, or remove a project when it is no longer needed.
  3. Assign jobs to employees. Send project visits to the correct staff so they can see the route and destination.
  4. Check the employee side. Confirm the worker receives the assignment and can open the route from their app.
  5. Follow progress. Watch arrival status and visit completion through the manager view and GPS page.

Helpful Tips

These small habits make the workflow easier and more accurate.

  • Keep the morning overview fresh. It helps you spot delays early.
  • Use clear project names. This makes assignment and tracking much easier.
  • Check the employee app after saving. Make sure the visit appears on the field side.
  • Review arrival status before closing the day. This helps prevent missed visits.
